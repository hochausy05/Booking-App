# 2–3 Minute Demo Script

Target duration: about 2 minutes 30 seconds. Record on a phone with the app already installed, notification permission reset if you want to show the prompt, and a clean demo-user booking history.

| Time | On screen | Narration / action |
| --- | --- | --- |
| 0:00–0:15 | Rooms tab | Introduce the app as a Vietnamese study-room booking demo. Point out the live room list and available-now status. |
| 0:15–0:40 | Search and filters | Type a room name, then combine building, capacity, and two equipment chips. Clear filters and briefly show the no-results state. |
| 0:40–1:05 | Room Detail | Open a room, scroll the seven-day date selector, and point out the fixed two-hour slots and disabled booked/past slots. |
| 1:05–1:35 | Booking | Select an available slot and book it. Show the success confirmation. If the OS permission prompt appears, accept or deny it and note that booking still succeeds either way. |
| 1:35–2:00 | My Bookings and QR | Open the bookings tab, show the upcoming booking, open its QR pass, and point out the booking details encoded for the pass. |
| 2:00–2:20 | Cancellation | Close the QR modal, cancel the booking, confirm the action, and show the cancelled state. |
| 2:20–2:30 | Closing | State that PostgreSQL rejects duplicate active slots and Realtime updates other clients. Mention the reminder is scheduled for 15 minutes before the slot when permission is granted. |

For a separate notification capture, record the real device notification when a previously booked test slot reaches its reminder time. Do not imply the notification was delivered during the short walkthrough unless it is shown.

Before recording, use a disposable demo booking and remove it after filming. Do not show `.env`, project credentials, or a real student identity.
